# Jove-Cartus
## Layout

- `index.html` — the encrypted main app (re-encrypt the plain source after every change).
- `rental-doc-sign.html` — public signing page.
- `fonts/` — self-hosted Public Sans, Source Serif 4 and Caveat (SIL OFL licences included). No third-party font requests.
- `vendor/xlsx-0.20.3.full.min.js` — SheetJS, self-hosted, used for .xlsx previews.
